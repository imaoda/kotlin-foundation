# 提供方与选择规则

| 提供方 | 采用范围 | 依赖策略 |
| --- | --- | --- |
| [Kotlin 标准库](kotlin.md) | AutoCloseable/use、普通类型与异常 | 核心唯一直接运行时依赖 |
| [kotlinx.coroutines](coroutines.md) | 状态、异步事件、任务、取消与监督 | 示例直接使用；核心不依赖 |
| [Arrow](community.md) | 需要类型化错误组合或资源作用域时评估 | 可选，当前未添加依赖 |
| [Reaktive / Essenty](community.md) | 已采用相应生态时优先复用 | 对照与条件选用，不统一加入 |
| [项目组件](../decisions/0001-reuse-and-scope.md) | 长期对象的同步所有权与通知契约 | 先对照成熟能力，再保留差异 |

记录推荐依据和验证证据：上游声明、编译通过、行为测试分别标记。只有实际使用的版本进入验证矩阵，参考库不虚构“兼容版本”。升级默认路径需重跑关联示例；若取消、异常或通知行为改变，重新审查推荐。

最近文档核验：2026-10-19。[本项目精确版本与范围](compatibility.md)。
